Per a fer un heatmap amb augment o disminució de concentracions respecte al grup REF amb la significància, la qual tenim en una altre taula d’excel.

On ho vaig aprendre: https://youtu.be/369PHkv1fPg?feature=shared. S’utilitza la llibreria pheatmap.

Transformem les dades a log2(FC)

En el cas de que tinguem els valors per cada observació, primer haurem de calcular el log2(FC) de les dades. En aquest cas cada rata apareixerà al heatmap, però també es podria fer amb les mitjanes, en el meu cas les vaig importar directament a l’excel.

També s’ha de tenir en compte que si volem fer arbres al heatmap no pot haver-hi cap valor buit, per tant quan no hi hagi observació, es posarà la mitjana del valor dins del grup (això s’ha de parlar i decidir en cada experiment, simplement modificar per que es substitueix).

data_log2<- data %>% 
  group_by(group) %>% 
  mutate(across(
    where(is.numeric),
    ~ ifelse(is.na(.), mean(., na.rm = TRUE), .)
  )) %>%  
  ungroup() %>%  
  mutate(across(
      3:last_col(), #canviar depenent de les variables que tingueu
      ~ .x / mean(.x [group == "REF"], na.rm = TRUE)
    )) %>% 
  mutate(across(3:last_col(), log2))

  • Fem el FoldChange (aquell valor dividit entre la mitjana de REF

    mutate(across( 3:last_col(), ~ .x / mean(.x [group == "REF"], na.rm = TRUE) )) %>%

  • Apliquem el logaritme amb base 2

    mutate(across(3:last_col(), log2))

results_kruskal <- longdata %>%
  filter(generation %in% c("M", "Cd1", "Cd21")) %>%
  group_by(generation, metabolite) %>%
  group_map(~ {
    # Kruskal–Wallis test
    model <- kruskal.test(value ~ group, data = .x)
    # tidy del test
    tidy_model <- tidy(model) %>%
      mutate(
        generation = .y$generation,
        metabolite = .y$metabolite,
        df = parameter 
      ) %>%
      select(generation, metabolite,df,statistic,p.value)
  }) %>%
  bind_rows() %>% 
  mutate(
    signif = case_when(
      is.na(p.value)  ~ "ns",
      p.value < 0.001 ~ "***",
      p.value < 0.01  ~ "**",
      p.value < 0.05  ~ "*",
      p.value < 0.1  ~ "·",
      TRUE            ~ "ns"))

Fem els data.frames de les dades convertides a log2(FC)

mean_data <- longdata %>% 
  group_by(generation, group, metabolite) %>% #que ho faci tot dins de la mateixa 
  summarise(mean = mean(value, na.rm = TRUE), .groups = "drop")

mat_data <- mean_data %>%  
  pivot_wider(names_from="metabolite", values_from="mean") %>%
  group_by(generation) %>% 
  mutate(across(
    2:last_col(),
    ~ .x / .x [group == "REF"]
  )) %>%  #FC
  ungroup() %>% 
  mutate(across(3:last_col(), log2)) %>%  #log2
  mutate(id = paste(generation, group, sep = "_")) %>% 
  column_to_rownames(var = "id") %>% 
  select(-generation, -group) %>%
  t()%>%                         # transposar
  as.matrix()
