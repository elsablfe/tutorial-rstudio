Patchwork i funcions

Si us hi heu fixat, al fer servir el facet_grid o el facet_wrap en els gràfics anteriors, tot s’observa igual. Els eixos són els mateixos, independentment de les mostres, tant l’y com l’x, per tant si un d’ells no té un grup és igual, deixa l’espai. A més a més no ens ensenya l’eix de la y en tots els gràfics, només el de l’esquerra. Això està bé de manera prèvia, però no per a publicar.

Per a solucionar-ho, i per a que no haguem d’estar fent els gràfics un a un i després ajuntant-los a power point, farem servir funcions i la llibreria patchwork.

Funciona de la següent manera: codifiquem totes les característiques en vectors fora del gràfic, i li indiquem a la funció que tregui la informació d’aquell vector. Per tant si volem canviar alguna característica la funció no l’hem de tocar, simplement hem de tocar el vector. Per altre banda al cridar la funció li direm quines variables volem expressar i si volem que ens agafi l’estadística de quin test ho ha de fer.

El patchwork funciona de manera que ens fa una graella, li podem indicar les mides, i ens va posant un gràfic a cada espai. D’aquesta manera tots tindran la mateixa mida i estaràn alineats. Per el que he hagut de fer em funciona bé.

Hi ha altres coses a tenir en compte, que jo he anat solucionant a la meva manera, segurament hi hauria millors maneres però em funciona. Comencem.

Estadística

Un cop ja haguem fet tots els tests necessaris i sapiguem de quin volem treure l’estadística, els codifiquem a aquest script. La funció posterior està feta de manera que ens agafarà la columna p.value i ens ho imprimirà. Per tal de que surtin només 3 decimals o <0.001 i <0.0001, ho modifiquem al crear la columna.

#U-Mann Whitney
results_umw <- longdata %>%
  group_by(tissue, variable) %>%
  wilcox_test(value ~ group) %>% 
  mutate(p.value = case_when(
    p >= 0.001 ~ sprintf("%.3f", p),       # deixa el valor tal qual, 3 decimals 
    p < 0.001 & p >= 0.0001 ~ "<0.001",  # entre 0.001 i 0.0001
    p < 0.0001 ~ "<0.0001"             # menor que 0.0001
  )) %>% 
  mutate(sig = case_when(
    p >= 0.05 ~ NA,        
    p < 0.05 & p >= 0.001 ~ "*",
    p < 0.001 & p >= 0.0001 ~ "**",  # entre 0.001 i 0.0001
    p < 0.0001 ~ "***"             # menor que 0.0001
  ))

#Ttest
results_ttest <- longdata %>%
  group_by(tissue, variable) %>%
  summarise(
    # fer t-test i guardar el resultat
    t_res = list(t.test(value ~ group, var.equal = F, alternative = "two.sided", conf.level=0.95)), #canviar a F si equal variances not assumed ; paired = F, es separen les variables amb ,
    .groups = "drop"
  ) %>%
  rowwise() %>%
  mutate(
    group1 = sub("mean in group ", "", names(t_res$estimate)[1]),
    group2 = sub("mean in group ", "", names(t_res$estimate)[2]),
    t = t_res$statistic,
    df = t_res$parameter,
    mean_diff = diff(t_res$estimate),  # Mean difference (group1 - group2)
    std_error = abs(mean_diff) / abs(t),  # Std. Error Difference
    p_one_sided = t_res$p.value / 2,
    p_two_sided = t_res$p.value,
    sig = case_when(
      is.na(t_res$p.value)        ~ "ns",
      t_res$p.value < 0.001       ~ "***",
      t_res$p.value < 0.01        ~ "**",
      t_res$p.value < 0.05        ~ "*",
      t_res$p.value < 0.1  ~ "·",
      TRUE                  ~ "ns"), #no cal, per visualitzar-ho millor
    conf_low = t_res$conf.int[1],
    conf_high = t_res$conf.int[2]
  ) %>%
  select(tissue, variable,group1, group2, t, df, p_one_sided, p_two_sided, sig, mean_diff, std_error) %>% 
mutate(p.value = case_when(
  p_two_sided >= 0.001 ~ sprintf("%.3f", p_two_sided),       # deixa el valor tal qual
  p_two_sided < 0.001 & p_two_sided >= 0.0001 ~ "<0.001",  # entre 0.001 i 0.0001
  p_two_sided < 0.0001 ~ "<0.0001"             # menor que 0.0001
  )) %>% 
  mutate(sig = case_when(
    p_two_sided >= 0.05 ~ NA,        
    p_two_sided < 0.05 & p_two_sided >= 0.001 ~ "*",
    p_two_sided < 0.001 & p_two_sided >= 0.0001 ~ "**",  # entre 0.001 i 0.0001
    p_two_sided < 0.0001 ~ "***"             # menor que 0.0001
  ))

Funcions

Com ja us he dit cridarem els gràfics a partir de funcions. Totes les d’aquest script són de barres, i n’he creat de diferents depenent de si vull estadística o no, si es tracta de una concentració o un percentatge, i si vull que em separi per sexes o no.

Funció per grup (concentració)

plot_bar <- function(vars, tiss) {
  plots <- map(vars, function(var){
    data_plot <- longdata %>% 
      filter(variable == var, tissue == tiss) %>% 
      na.omit()
    
    ggplot(data_plot, aes(x = group, y = value, colour = group)) +
      geom_jitter(alpha = 0.5, width = 0.12) +
      scale_x_discrete(
        limits = group_order,
        expand = expansion(add = 1)) +
      scale_y_continuous(
        limits = c(0, NA),
        expand = expansion(mult = c(0, 0.05))) +
      stat_summary(fun = mean, geom = "col", width = 0.5, fill = NA, linewidth = 0.6) +
      stat_summary(fun.data = mean_se, geom = "errorbar", width = 0.25, linewidth = 0.6) +
      scale_colour_manual(values = group_color, breaks = group_order) +
      labs(
        x = NULL,
        y = paste0("[ ", variable_name[[var]], " ] ", conc[[tiss]]),
        colour= "Group")+
      theme(
        plot.title = element_text(hjust = 0.5),
        strip.background = element_blank(),
        panel.spacing = unit(0.5, "cm"),
        aspect.ratio = 1.75)
  })}

Quan cridem a la funció (function(vars, tiss)) ens demanarà la informació de quines variables agafem i quins teixits. La funció està dividida en dues parts:

  • data_plot <- filtrarà les dades que li he demanat
  • ggplot(data_plot, aes()) agafarà aquestes dades filtrades i ens crearà els gràfics.

A scale_x_discrete no posem breaks, ja que sinó ens apareixerien sempre tots els grups, i com que no tots els tenen, no ho volem.

A labs(y = paste0("[ ", variable_name[[var]], " ] ", conc[[tiss]])), ens està agafant la informació de quina concentració és depenent del teixit que li hem indicat i ens la imprimeix.

Funció per grup amb estadística

Aquí la cosa es complica una mica, però un cop ho tens solucionat tot, en pots fer tants com vulguis.

plot_bar_sig <- function(vars, tiss, results_sig) {
 plots <- map(vars, function(var){
  data_plot <- longdata %>% 
    filter(variable == var, tissue == tiss) %>% 
    na.omit()
  
  sig_graph <- results_sig %>% 
    filter(tissue == tiss, variable == var, p.value < 0.05) %>% 
    mutate(
      y.min = max(data_plot$value[data_plot$variable == var], na.rm = TRUE),
      y.position = y.min*1.1 + seq(1, by = 1, length.out = n())) 
  
  # Calcula màxim eix Y segons dades i brackets
  y.max.data <- max(data_plot$value, na.rm = TRUE)
  y.max.brackets <- if(nrow(sig_graph) > 0) max(sig_graph$y.position, na.rm = TRUE) else 0
  y.axis.max <- max(y.max.data*1.2, y.max.brackets)
  
    ggplot(data_plot, aes(x = group, y = value, colour = group)) +
    geom_jitter(alpha = 0.5, width = 0.12) +
    scale_x_discrete(
      limits = group_order,
      expand = expansion(add = 1)) +
    scale_y_continuous(
      limits = c(0, y.axis.max),
      expand = expansion(mult = c(0, 0.05))) +
    stat_summary(fun = mean, geom = "col", width = 0.5, fill = NA, linewidth = 0.6) +
    stat_summary(fun.data = mean_se, geom = "errorbar", width = 0.25, linewidth = 0.6) +
    scale_colour_manual(values = group_color, breaks = group_order) +
    labs(
      x = NULL,
      y = paste0("[ ", variable_name[[var]], " ] ", conc[[tiss]]),
      colour= "Group")+
    theme(
      plot.title = element_text(hjust = 0.5),
      strip.background = element_blank(),
      panel.spacing = unit(0.5, "cm"),
      aspect.ratio = 1.75)+
    stat_pvalue_manual( 
      sig_graph,
      tip.length = 0.025,
      bracket.nudge.y = -1, 
      hide.ns = TRUE,
      size = 3)
})}

Funció per grup i sexe

Si volem mirar a veure si hi ha diferències entre sexe una primera aproximació seria fer-ho amb un gràfic:

plot_bar_sex <- function(vars, tiss) {
  plots <- map(vars, function(var){
    data_plot <- longdata %>% 
      filter(variable == var, tissue == tiss) %>% 
      na.omit() %>% 
      mutate(group_sex = paste0(group, "_", sex))
    
  data_plot %>% 
    group_by(sex) %>%
    ggplot(aes(x = group_sex, y = value, colour = group_sex)) +
      geom_jitter(alpha = 0.5, position = position_jitterdodge(dodge.width = 0.75, jitter.width = 0.25)) +
      scale_x_discrete(
        limits = group_sex,
        expand = expansion(add = 1),
        label = group_sex_name) +
      scale_y_continuous(
        limits = c(0, max(data_plot$value, na.rm = TRUE) * 1.2),
        expand = expansion(mult = c(0, 0.05))) +
      stat_summary(fun = mean, geom = "col", width = 0.5, fill = NA, linewidth = 0.6, position = position_dodge(width = 0.75)) +
      stat_summary(fun.data = mean_se, geom = "errorbar", width = 0.25, linewidth = 0.6, position = position_dodge(width = 0.75)) +
      scale_colour_manual(values = sex_color, breaks = group_sex, label = group_sex_name) +
      labs(
        x = NULL,
        y = paste0("[ ", variable_name[[var]], " ] ", conc[[tiss]]),
        colour= "Group & Sex")+
      theme(
        plot.title = element_text(hjust = 0.5),
        strip.background = element_blank(),
        panel.spacing = unit(0.5, "cm"),
        aspect.ratio = 1.75,
        axis.text.x = element_text(angle = 45, hjust = 1))
  })}

plot_perc <- function(vars) {
  longdata %>%
  filter(variable %in% vars) %>% 
  mutate(variable = factor(variable, levels = vars)) %>% 
  group_by(tissue, group, variable) %>% 
  na.omit() %>% 
  summarise(value = mean(value), .groups = "drop") %>%
  ggplot(aes(y=group, x= value, fill=variable))+
  geom_col(position = position_stack(reverse = F), width = 0.8)+
  scale_fill_manual(values = perc_color,
